# Claude SEO guidelines

Follow first-principles SEO audits:
1. Check Largest Contentful Paint (LCP < 2.5s), Interaction to Next Paint (INP < 200ms), and Cumulative Layout Shift (CLS < 0.1).
2. Validate Schema.org JSON-LD (e.g. Organization, LocalBusiness, Article, Product).
3. Optimize for AI search/generative search by creating clear question-based headings and high entity presence.
4. Ensure E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness) guidelines from Google's helpful content guide.
